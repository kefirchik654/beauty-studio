# Salon booking bot: стартовый каркас

Реализовано по спецификации: клиентский сценарий записи (услуга → мастер → дата → время → подтверждение),
«Мои записи» с отменой, информационные разделы, уведомления администратору о новых и отменённых записях.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

createdb salonbot
psql salonbot -f schema.sql
psql salonbot -f seed.sql          # тестовый салон BEAUTY STUDIO

export BOT_TOKEN=...               # токен от @BotFather
export DATABASE_URL=postgresql://user:pass@localhost:5432/salonbot
export SALON_ID=1
export ADMIN_CHAT_ID=123456789     # необязательно: ваш Telegram ID для уведомлений
python -m app.main
```

Тесты логики слотов (не требуют базы и Telegram): `python tests/test_slots.py`

## Структура

| Файл | Назначение |
| --- | --- |
| `schema.sql` | Таблицы; exclusion constraint запрещает пересечение активных записей одного мастера |
| `seed.sql` | Тестовые данные |
| `app/services/slots.py` | Чистый расчёт свободных слотов (график − перерывы − записи − буфер − мин. время до записи) |
| `app/services/booking.py` | Слоты по мастерам, «любой мастер», создание записи с повторной проверкой |
| `app/db.py` | Все SQL-запросы, везде с `salon_id` |
| `app/bot/handlers.py` | Экраны и переходы |
| `app/bot/keyboards.py`, `callbacks.py`, `texts.py` | Кнопки, callback-данные, тексты |

## Что сделано и что нет

Сделано: запись, «любой мастер», защита от двойного нажатия и гонки, отмена с подтверждением и правилом
«не позже чем за N часов», правильные часовые пояса.

Не сделано (следующие шаги по спецификации): перенос записи, календарь на месяц, история посещений,
запрос телефона, напоминания (воркер), веб-панель администратора, подключение нескольких ботов
через webhook, Row-Level Security, разбивка услуг на категории и страницы, карточки мастеров с фото.

## Важно

- Данные салона читаются один раз при запуске: после правки настроек перезапустите бота.
- Для SaaS замените `SALON_ID` на определение салона по боту (таблица `bots`, webhook `/webhook/{bot_id}`).
- Код бота не запускался в этой среде (не было aiogram и PostgreSQL); проверены только компиляция
  модулей и юнит-тесты расчёта слотов. Первый запуск с реальной базой, скорее всего, потребует
  небольших правок.
